# 0.6.0の操作と比較

## 音声認識

Quest起動時は音声ON、比較開始モデルはReazonSpeech k2-v2です。初回のみマイク許可と同梱モデルの展開が必要です。パネルのモデル名ボタンでSenseVoice Smallと交互に切り替えます。切替時はマイクと待機中の発射を止め、旧モデルの処理終了・解放を待ってから次を読み込みます。2モデルを同時に保持しません。音声OFF中にモデルを変えた場合はOFFを維持します。

アプリ起動ごとにReazonSpeech・音声ONで開始します。スリープ中は録音を止め、復帰時は停止前にONだった場合だけ再開します。手動でOFFにしていた場合は復帰後もOFFです。モデル選択の永続保存や、録音した同じ発話を両方へ再投入する比較モードはまだありません。

ReazonSpeechの配布元は `reazon-research/reazonspeech-k2-v2`、固定リビジョン `291488c8151be24d7da4bf7af26e533fad96e407`。encoderとjoinerはINT8、decoderはFP32、modified beam search（4候補）・2スレッドです。VADは両モデルでSileroを共有します。`python tools/setup_speech.py` が両モデルを準備し、APKへ同梱します。APIサービス、追加の課金、音声アップロードはありません。

## コントローラーと手

| 操作 | コントローラー | 手のみ |
| --- | --- | --- |
| パネル選択 | 右のポインター＋トリガー | 右手のポインター＋親指と人差し指のピンチ |
| パネルを正面へ | 右B | 右の親指と中指をピンチ |
| パネル表示切替 | 右A | 正面へ呼び戻す操作を使う |
| VR内移動 | 左スティック | 左の親指と人差し指をピンチし、その位置から手を前後左右にずらす。離すと停止 |
| VR内回転 | 右スティック左右、30度ずつ。中央に戻すと再入力 | パネルの「左へ30度」「右へ30度」 |
| MR位置合わせ | 右グリップ | 右手を目印に置き「目印を確定」 |

手の移動は15cmのずらしで最大入力、移動速度は最大1.5m/sです。手の追跡喪失やシステムジェスチャー中は手入力を無効にします。MR中は仮想移動しません。VR→MRで仮想移動・回転分を戻し、実際に歩いた頭の位置は追跡に任せます。

## 部屋への衝突

マイク準備後に部屋データを読み込みます。空間データの許可画面が出たら許可してください。部屋設定がない場合、Metaの空間設定が起動することがあります。「部屋読込」で再試行できます。パネルにメッシュ／壁・床・家具の判定数を表示します。許可拒否・未設定では実際の机などに当たると保証できません。

新機能の実機確認は、手追跡ON、両モデルを同じ文で試す、VR移動後に発話する、MRへ戻る、机・壁へ文字を飛ばす、スリープ復帰をそれぞれ確認します。PCテストはQuestでの体感・性能の代わりにはなりません。
